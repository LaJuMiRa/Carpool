# Carpool

Familien-App für drei Autos. Details: `CLAUDE.md`.

## Einrichten

```sh
brew install xcodegen
npm install                                   # Supabase CLI
cp Config/Secrets.example.xcconfig Config/Secrets.xcconfig
xcodegen generate && open Carpool.xcodeproj
# Backend: Supabase-Cloud-Projekt „Carpool" (ybceqcsvlhbbzjlczvaq)
```
